Set up the push

Copy this prompt into a Kody-connected agent:

Please set up a daily feed push for my kody-os app "daily-feed". Using Kody execute against kody:@hypercubed/kody-os, read its current state, prepend one new RSS item (newest first, at most 14 items total), and set the full feed with the act action "set_feed". Do not overwrite the feed if the current feed cannot be read or parsed. The feed is RSS XML with one item per entry, each with title, link, pubDate, and a plain-text description.

– App id: daily-feed
– Action: set_feed
– Format: RSS XML, newest first, at most 14 entries

The app will show the latest entry once a push lands, with Previous and Next to step through entries.
