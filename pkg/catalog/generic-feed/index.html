Set up the feed

Copy this prompt into a Kody-connected agent:

Please set up a feed push for my kody-os app "generic-feed". Fetch the RSS feed at the URL below, then using Kody execute against kody:@hypercubed/kody-os, read the app's current state and set the full feed with the fetched items using the act action "set_feed". Do not overwrite the feed if the fetch fails, the fetched XML cannot be parsed, or the current feed cannot be read or parsed. The feed is RSS XML with one item per entry, each with title, link, pubDate, and a plain-text description, newest first, at most 14 entries.

– RSS feed URL: [paste the RSS feed URL here]
– App id: generic-feed
– Action: set_feed
– Format: RSS XML, newest first, at most 14 entries

The app will show the latest entry once a push lands, with Previous and Next to step through entries.
